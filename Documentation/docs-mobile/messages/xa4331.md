# .NET for Android error XA4331

## Example message

```
error XA4331: Could not generate JNI remapping asset from 'r8-jni-remap.xml' to 'jni-remap.bin': ...
```

## Issue

The build could not read JNI replacement XML or write its versioned binary asset.
The diagnostic includes the input and output paths and the underlying failure.
Missing input files, malformed XML, invalid UTF-8 strings, or an unwritable output
directory are errors, not empty remapping data.

Applications without replacement entries receive a valid empty binary asset.
Missing source signatures remain wildcards, and missing target signatures retain
the signature used by the caller.

## Solution

Fix the reported input or output path and the underlying failure. If the XML was
generated by .NET for Android, clean and rebuild the application. If the error
persists, [report an issue](https://github.com/dotnet/android/issues/new/choose)
with a binary build log and the affected remapping XML.
