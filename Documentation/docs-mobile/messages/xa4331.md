# .NET for Android error XA4331

## Example message

```
error XA4331: Could not generate JNI remapping asset from 'remap.xml' to 'jni-remap.bin': Duplicate JNI remapping method 'a/B.run()V'.
```

## Issue

The merged JNI remapping XML could not be read, has ambiguous duplicate entries,
contains a name that cannot be represented as UTF-8, or the binary asset could
not be written. The diagnostic identifies the input, output, and specific cause.

## Solution

Fix the reported remapping input or output path. If the input comes from R8,
correct conflicting remapping rules or clean and rebuild the application.
