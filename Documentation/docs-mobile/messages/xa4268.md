# .NET for Android warning XA4268

## Example messages

```text
warning XA4268: The Kotlin metadata for Java method 'com/example/Widget.put(Ljava/lang/Object;)V' matches more than one Kotlin function: put(I)V, put(Ljava/lang/String;)V. The Kotlin fixups for this method are skipped.
```

## Issue

When a binding project binds a Kotlin library, the build reads the Kotlin
metadata in each `.class` file. It uses the metadata to find the Kotlin
function for each Java method. Then it applies Kotlin fixups to the Java
method. For example, it uses the Kotlin parameter names, it hides `internal`
functions, and it uses unsigned types.

This warning occurs when more than one Kotlin function matches the same Java
method. The build cannot know which function is correct. If it used the wrong
function, the binding could get incorrect parameter names or types, or the
method could be hidden. Thus the build does not apply the Kotlin fixups to this
method. The method is bound as a usual Java method.

## Solution

Usually, you do not have to do anything. Examine the generated C# API for the
Java method in the message. If the API is not correct, use
[metadata transforms](../binding-libs/customizing-bindings/java-bindings-metadata.md)
in `Transforms/Metadata.xml` to change it.

If you own the Kotlin library, give the Kotlin functions different names, or
use the `@JvmName` annotation to give them different Java names.

To ignore this warning, add `XA4268` to the `$(NoWarn)` property in the
binding project.
