# .NET for Android warning XA0108

## Issue

.NET for Android no longer runs the Android `lint` tool during the build,
so `$(AndroidLintEnabled)` has no effect.

## Solution

Remove `$(AndroidLintEnabled)` from the project file. To check your app,
run the [Android `lint` tool](https://developer.android.com/studio/write/lint)
directly.
