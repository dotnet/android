# .NET for Android warning XA0108

## Issue

This message indicates that the .NET for Android tooling was unable to determine the version of the `lint` tool.
The tooling falls back to version 1.0 when neither the version command nor a
development lint JAR identifies the version. Default disabled checks are selected
using that fallback version; command-line tools retain all default disabled checks.

## Solution

Consider submitting a [bug][bug] if you are getting this warning under normal
circumstances.
