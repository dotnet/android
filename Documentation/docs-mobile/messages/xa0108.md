# .NET for Android warning XA0108

## Example messages

```
warning XA0108: Android lint support was removed. The 'AndroidLintEnabled' MSBuild property has no effect. Remove it, and run the 'lint' tool from the Android SDK command-line tools directly.
```

## Issue

The project sets the `$(AndroidLintEnabled)` MSBuild property to `true`.
.NET for Android does not run the Android `lint` tool during the build.
The `$(AndroidLintEnabledIssues)`, `$(AndroidLintDisabledIssues)`, and
`$(AndroidLintCheckIssues)` properties, and the `@(AndroidLintConfig)` build
action, also have no effect.

## Solution

Remove `$(AndroidLintEnabled)` and the related properties and items from the
project file.

To check your Android resources and manifest, run the `lint` tool from the
Android SDK command-line tools directly. See the
[Android lint documentation](https://developer.android.com/studio/write/lint).
