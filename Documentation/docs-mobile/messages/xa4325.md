# .NET for Android error XA4325

## Example message

```
error XA4325: Failed to generate the JNI remapping data. The R8 mapping file 'mapping.txt' was not found.
```

## Issue

The build could not generate runtime JNI remapping data. The merged remapping
XML may be missing or malformed. In runtime-remapping mode, the final R8
mapping, linked managed metadata, or NativeAOT retention object may be
missing, unreadable, malformed, or contain entries that cannot be represented
unambiguously by the runtime lookup tables.

For CoreCLR applications, this error can also mean the generated bootstrap
configuration is missing or invalid. The bootstrap configuration and JNI
remapping table are separate data symbols in the same per-ABI
`libbinary_blobs.so`; the assembly store is a separate library.

## Solution

Fix the reported input path or earlier build failure. If the files were
generated by .NET for Android, clean and rebuild the application. If the
error reports ambiguous entries, use R8 keep rules so the affected Java
classes or members are not merged into the same runtime lookup key.

For NativeAOT, supply the original ILC object with its ELF symbols and
relocations intact, rather than a stripped object or a linked native library.
