# .NET for Android error XA4267

## Example message

```text
error XA4267: The 'llvm-ir' type map implementation is no longer supported. Remove the AndroidTypeMapImplementation property or set it to 'trimmable'.
```

## Issue

The project sets `AndroidTypeMapImplementation` to `llvm-ir`, which is no longer
supported.

## Solution

Remove the `AndroidTypeMapImplementation` property to use the default
`trimmable` type map, or set it to `trimmable` explicitly.
