# .NET for Android warning XA5307

## Issue

`InstallAndroidDependencies` asked the Android CLI to install an Android SDK package, but the package was not found in the Android SDK directory afterwards.

## Solution

Make sure that the package name and version are correct and that the Android SDK directory is writable. Review the Android CLI output in the build log for more details.
