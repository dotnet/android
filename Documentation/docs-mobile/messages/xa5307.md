# .NET for Android error XA5307

## Example messages

```text
error XA5307: The Android CLI downloaded from `{url}` has SHA-256 `{actual}`, but SHA-256 `{expected}` was expected. The Android CLI will not be used.
```

## Issue

`InstallAndroidDependencies` downloads a pinned version of Google's
[Android CLI](https://developer.android.com/tools/agents/android-cli). Before it
runs the Android CLI, it makes sure that the SHA-256 hash of the downloaded file
is the same as the hash included with the .NET for Android SDK. The hashes are
different, so the Android CLI is not used. A proxy that changes downloads, an
incomplete download, or a changed file on the server can cause this error.

## Solution

Check network access to the download URL, and try again. Use an up-to-date
.NET for Android SDK. If the error continues, report it with the URL and both
hashes. Do not use an Android CLI whose hash is not correct.
