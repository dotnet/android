# .NET for Android error XA5306

## Issue

`InstallAndroidDependencies` needs to install Android SDK packages, but the Android SDK license agreements have not been accepted.

## Solution

Read the [Android SDK License Agreement](https://developer.android.com/studio/terms), then accept it by setting `$(AcceptAndroidSDKLicenses)` to `true`:

```dotnetcli
dotnet build -t:InstallAndroidDependencies -p:AcceptAndroidSDKLicenses=true
```
