# .NET for Android error XA5306

## Example messages

```text
error XA5306: The Android CLI is not available for this operating system and architecture: `{os}` `{architecture}`.
```

## Issue

`InstallAndroidDependencies` installs Android SDK packages with Google's
[Android CLI](https://developer.android.com/tools/agents/android-cli). Google
does not publish the Android CLI for the current operating system and processor
architecture. The Android CLI is available for Windows x64, macOS (x64 and
Arm64), and Linux (x64 and Arm64).

## Solution

Run `InstallAndroidDependencies` on a supported operating system and
architecture. Alternatively, install the Android SDK packages with Android
Studio or the Android SDK command-line tools, and set `$(AndroidSdkDirectory)`
to that Android SDK.
