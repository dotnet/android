# .NET for Android error XA5311

## Example messages

```text
error XA5311: The version 'latest' of Android SDK dependency 'platform-tools' is not a valid version.
```

## Issue

The `Version` metadata of the `platform-tools` dependency passed to
`InstallAndroidDependencies` is not a version number. It is used as the minimum
version when selecting `platform-tools` from the Android CLI catalog.

## Solution

Set the `Version` metadata to a version number, such as `37.0.3`, or remove
it to accept any installed version of the package.
