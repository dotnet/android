# .NET for Android error XA4248

## Example message

```
error XA4248: Could not find NuGet package 'Xamarin.Kotlin.StdLib' version '1.9.0' in lock file. Ensure NuGet Restore has run since this <PackageReference> was added.
```

## Issue

The NuGet lock file has not been generated and thus Java dependencies from NuGet packages
cannot be resolved, or it does not contain the requested package version.

With Central Package Management, Java dependency verification uses the restored
package version from `project.assets.json` because `PackageReference` items do
not specify `Version` metadata. If the assets file contains multiple versions of
the same package and no version is specified, verification reports this error
rather than selecting an arbitrary version.

## Solution

Run NuGet Restore for the project to ensure the lock file has been generated.

If multiple restored versions prevent Java dependency verification, specify
`JavaArtifact` metadata on the `PackageReference` to identify the Java
dependencies supplied by that package.
