# .NET for Android error XA1052

## Example messages

```dotnetcli
error XA1052: Native runtime linking is no longer supported. Remove the '_AndroidEnableNativeRuntimeLinking' MSBuild property or set it to 'false'.
```

## Issue

`_AndroidEnableNativeRuntimeLinking` selected an experimental "unified" CoreCLR
native runtime that linked the CoreCLR runtime directly into a single native
library. That feature depended on the same app-generated, app-compiled LLVM IR
bootstrap (environment, type map, compressed assemblies, and JNI remapping)
that CoreCLR and NativeAOT builds no longer produce, so it can no longer be
enabled.

## Solution

Remove the property, or set it to `false`, in the project file:

```xml
<PropertyGroup>
  <_AndroidEnableNativeRuntimeLinking>false</_AndroidEnableNativeRuntimeLinking>
</PropertyGroup>
```
