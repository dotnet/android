# .NET for Android error XA1052

## Example messages

```dotnetcli
error XA1052: The 'Microsoft.Android' NuGet package is required to build 'net12.0-android' projects. Add <PackageReference Include="Microsoft.Android" Version="37.0.0" /> to the project file.
```

## Issue

Starting with .NET 12, the Android build is part of the `Microsoft.Android`
NuGet package. The `android` workload only installs this package for offline
restore; it does not add the package to projects.

## Solution

Add a `PackageReference` to the `Microsoft.Android` NuGet package, with the
version from the error message:

```xml
<ItemGroup>
  <PackageReference Include="Microsoft.Android" Version="37.0.0" />
</ItemGroup>
```

The `$(MicrosoftAndroidPackageVersion)` MSBuild property contains the
version of the installed `android` workload.
