# .NET for Android warning XA0119

## Issue

This warning indicate a non-ideal configuration in your
.NET for Android project.

## Solution

Remove the following options from `Debug` configurations:

* Linker
  * `<AndroidLinkMode>SdkOnly</AndroidLinkMode>`
  * `<AndroidLinkMode>Full</AndroidLinkMode>`
* AOT
  * `<AotAssemblies>True</AotAssemblies>`
  * `<RunAOTCompilation>True</RunAOTCompilation>`
* ReadyToRun
  * `<PublishReadyToRun>True</PublishReadyToRun>`
* Code Shrinker
  * `<AndroidEnableProguard>True</AndroidEnableProguard>`
  * `<EnableProguard>True</EnableProguard>`
  * `<AndroidLinkTool>proguard</AndroidLinkTool>`
  * `<AndroidLinkTool>r8</AndroidLinkTool>`

For supported .NET 10-and-earlier projects that use Mono, remove the
following from `Release` configurations:

* Hot Reload support
  * `<UseInterpreter>true</UseInterpreter>`

*DO* use the following options for `Debug` configurations:

* `<AndroidLinkMode>None</AndroidLinkMode>`
* `<AndroidEnableFastDeployment>True</AndroidEnableFastDeployment>`
* `<UseInterpreter>true</UseInterpreter>` for supported .NET
  10-and-earlier projects that use Mono

*DO* use the following options for `Release` configurations:

* `<AndroidEnableFastDeployment>False</AndroidEnableFastDeployment>`
* `<RunAOTCompilation>True</RunAOTCompilation>` for supported .NET
  10-and-earlier projects that use Mono
* `<PublishReadyToRun>True</PublishReadyToRun>` (for CoreCLR, when trimming is enabled)

Consider submitting a [bug][bug] if you are getting one of these
warnings under normal circumstances.

[bug]: https://github.com/dotnet/android/wiki/Submitting-Bugs,-Feature-Requests,-and-Pull-Requests
