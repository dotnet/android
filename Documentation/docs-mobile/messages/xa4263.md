# .NET for Android error XA4263

## Example message

```text
error XA4263: The exported member 'Peer.Get' has unsupported signature type 'ManagedValue'. Use a Java peer type, a supported managed-to-Java mapping, or [ExportParameter].
```

## Issue

An `[Export]` method or `[ExportField]` initializer uses a managed parameter or return type that has no Java type mapping.
The type cannot be represented safely in the generated Java declaration.

## Solution

Use a primitive, string, array, Java peer, or another supported managed-to-Java type. For `Stream` or `XmlReader`, apply `[ExportParameter]` with the appropriate Java mapping.
