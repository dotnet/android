# .NET for Android error XA1049

## Example messages

```dotnetcli
error XA1049: The 'AndroidEnableMarshalMethods' MSBuild property is no longer supported. Remove it or set it to 'false'.
```

## Issue

The llvm-ir type map and its marshal-method assembly rewriter are no longer
supported. Setting `$(AndroidEnableMarshalMethods)` to `true` cannot enable
marshal methods with the trimmable type map.

## Solution

Remove the property or set it to `false` in the project file:

```xml
<PropertyGroup>
  <AndroidEnableMarshalMethods>false</AndroidEnableMarshalMethods>
</PropertyGroup>
```
