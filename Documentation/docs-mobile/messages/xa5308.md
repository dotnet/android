# .NET for Android error XA5308

## Issue

`InstallAndroidDependencies` could not install the Java SDK into the configured directory. The directory may be empty, a root or home directory, or an existing directory that does not contain a Java SDK.

## Solution

Set `$(JavaSdkDirectory)` to an empty directory, or to an existing Java SDK directory, that does not require administrator access:

```dotnetcli
dotnet build -t:InstallAndroidDependencies -p:JavaSdkDirectory=path/to/jdk
```
