# .NET for Android error XA5308

## Example messages

```text
error XA5308: The Android CLI failed with exit code {code} while it installed Android SDK packages. Output:
{output}
```

## Issue

`InstallAndroidDependencies` runs `android sdk install` from Google's
[Android CLI](https://developer.android.com/tools/agents/android-cli) to install
Android SDK packages. The Android CLI stopped with an error. The error message
includes the last part of the Android CLI output.

## Solution

Read the Android CLI output in the error message. Make sure that you can write
to `$(AndroidSdkDirectory)`, that you have network access, and that the disk has
sufficient free space. Then try again.
