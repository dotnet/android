# .NET for Android error XA5305

## Example messages

```text
error XA5305: Could not verify the Microsoft OpenJDK archive signature for '{url}'. The archive will not be installed. {reason}
```

## Issue

`InstallAndroidDependencies` could not download or verify the detached signature
for the Microsoft OpenJDK archive. Installation stops before the archive is
extracted. A missing signature, an untrusted signing key, or changed archive
contents cause this error.

## Solution

Check the error details and network access to the archive URL and its `.sig`
file. Use an up-to-date .NET for Android SDK. If the error continues, report it
with the archive URL and error details. Do not install an archive whose signature
cannot be verified.
