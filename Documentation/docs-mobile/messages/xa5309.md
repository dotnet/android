# .NET for Android error XA5309

## Example messages

```text
error XA5309: The Android CLI failed with exit code {code} while it listed Android SDK packages. Output:
{output}
```

## Issue

`InstallAndroidDependencies` could not query Google's Android CLI package catalog
to resolve a stable `platform-tools` version. Installation stops rather than
guessing a version.

## Solution

Read the Android CLI output in the error message. Check network access to
Google's Android SDK repository, then try again.
