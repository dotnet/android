# .NET for Android error XA3007

## Issue

The native linker could not produce a shared library. For NativeAOT builds in
.NET 11 and later, this can also indicate that the Android NDK's `llvm-objcopy`
could not prepare the ARM runtime archive for linking.

## Solution

Examine the logged native tool output for missing objects, libraries, or
unresolved symbols. NativeAOT uses `ld.lld`, CRT objects, sysroot libraries, and
compiler runtime libraries from the installed Android NDK. Check that
`AndroidNdkDirectory` points to a complete installation.
