# .NET for Android warning XA1035

## Example messages

```
warning XA1035: The 'BundleAssemblies' property is deprecated and no longer affects the build. Remove it. For supported .NET 10-and-earlier Mono projects, use 'AndroidUseAssemblyStore' with 'AndroidEnableAssemblyCompression' for the former behavior. .NET 11 CoreCLR controls packaged assembly-store behavior and needs no replacement setting.
```

## Issue

This warning is emitted whenever `$(BundleAssemblies)` is `true`,
regardless of the selected runtime. The property no longer affects the
build.

## Solution

Edit your project file and remove the `$(BundleAssemblies)` property.

For supported .NET 10-and-earlier projects that use Mono,
`$(AndroidUseAssemblyStore)` together with
`$(AndroidEnableAssemblyCompression)` provides the former behavior when
it is needed.

For .NET 11 CoreCLR projects, do not add a replacement property.
CoreCLR controls its packaged assembly-store behavior.
