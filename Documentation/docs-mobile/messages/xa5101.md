# .NET for Android error XA5101

## Issue

The Android NDK installation is missing a required toolchain directory.
NativeAOT also requires the host toolchain's sysroot and Clang runtime libraries.
Checked builds require Clang sanitizer runtime libraries; discovery uses
`lib/clang` or the older `lib64/clang` layout under the host LLVM toolchain.
When no usable Clang runtime directory is found, the error lists both search
roots. A root may exist but lack the version-specific `lib/linux` directory.

## Solution

Install a complete Android NDK for the build host and check the directory named
in the error. Set `AndroidNdkDirectory` if using a custom installation.
