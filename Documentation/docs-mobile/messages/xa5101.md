# .NET for Android error XA5101

## Issue

The Android NDK installation is missing a required toolchain, sysroot, or Clang
runtime directory. The error includes the missing directory's path.

## Solution

Install or repair the official Android NDK for the build host. If
`$(AndroidNdkDirectory)` is set, it must point to the NDK root containing
`source.properties` and `toolchains/llvm/prebuilt`, not to its `bin` directory.

NativeAOT requires the NDK tools and libraries. Opt-in
`$(AndroidStripNativeLibraries)=true` requires its `llvm-strip` tool.
Ordinary CoreCLR builds do not require an NDK.
