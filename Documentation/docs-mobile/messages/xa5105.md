# .NET for Android error XA5105

## Issue

A required tool could not be found in the Android NDK. The error identifies the
tool and searched path. NativeAOT uses `ld.lld` and `llvm-objcopy`; enabling
`$(AndroidStripNativeLibraries)` requires `llvm-strip`.

## Solution

Repair or reinstall the official Android NDK for the build host. Check
`$(AndroidNdkDirectory)` if using a custom installation. Tools are resolved from
`toolchains/llvm/prebuilt/<host>/bin` in that installation, not from the system
`PATH` or a bundled .NET for Android toolchain.
