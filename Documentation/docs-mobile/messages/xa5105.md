# .NET for Android error XA5105

## Issue

A required Android NDK utility was not found. NativeAOT uses `ld.lld` and
`llvm-objcopy`; `AndroidStripNativeLibraries=true` uses `llvm-strip`.

## Solution

Check the utility and searched path named in the error. Reinstall an incomplete
NDK or set `AndroidNdkDirectory` to a complete installation for the build host.
The build does not fall back to bundled tools or silently skip requested
native library stripping.
