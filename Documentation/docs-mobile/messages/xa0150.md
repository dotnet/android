# .NET for Android warning XA0150

## Example messages

> warning XA0150: NuGet package 'Some.Old.Package' version '1.2.3' contains assembly '/path/to/Some.Old.Package.dll' with Android library content embedded in the legacy Xamarin.Android format. Support for this format is deprecated and will be removed in a future version of .NET for Android. Use a newer version of this NuGet package or notify the library author.

> warning XA0150: Assembly '/path/to/SomeLibrary.dll' contains Android library content embedded in the legacy Xamarin.Android format. Support for this format is deprecated and will be removed in a future version of .NET for Android. Use a newer version of this assembly or notify the library author.

## Issue

A referenced assembly (typically from an older Xamarin.Android class
library or a NuGet package targeting `MonoAndroid`) contains Android
resources, assets, Java libraries, or native libraries embedded as
`__AndroidLibraryProjects__.zip`, `__AndroidNativeLibraries__.zip`, or
`*.jar` managed resources. Only "classic" Xamarin.Android projects
produce this format; .NET for Android class libraries place this content
in an `.aar` file next to the assembly instead.

.NET for Android still extracts this content, but support for the
legacy format is deprecated and will be removed in a future version.

This is closely related to the
[NU1703](https://learn.microsoft.com/nuget/reference/errors-and-warnings/nu1703)
warning that NuGet emits for packages still targeting the deprecated
`MonoAndroid` framework.

## Solution

Update to a version of the NuGet package or library that targets
`net-android` (.NET for Android). If you maintain the library, rebuild
it as a .NET for Android class library so that its Android content is
packaged in an `.aar` file.
