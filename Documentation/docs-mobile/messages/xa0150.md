# .NET for Android warning XA0150

## Example message

> warning XA0150: Assembly 'Some.Library' from '/path/to/Some.Library.dll' required the deprecated GC.KeepAlive compatibility fixup. This fixup will no longer be applied in the next .NET for Android release. Update to a library version built with the current .NET for Android toolchain, or contact the library author.

## Issue

The affected assembly contains binding methods which do not include the
`GC.KeepAlive` calls needed to keep Java peer arguments alive during JNI
calls. .NET for Android applied the compatibility fixup to the build output
so those calls are made at runtime.

This warning is emitted only when the assembly was changed. It does not
indicate that all .NET for Android assemblies are old.

## Solution

Update the library to a version built with the current .NET for Android
toolchain. If you own the library, rebuild it with the current .NET for
Android workload. If the assembly comes from a third-party package,
contact its author and request an updated build.

The compatibility fixup will no longer be applied starting with the next
.NET for Android release.
