# .NET for Android error XA4330

## Example message

```
error XA4330: The native library 'Libraries/arm64-v8a/libcustom.so' cannot be packaged as 'lib/arm64-v8a/libbinary_blobs.so' because 'libbinary_blobs.so' is reserved for .NET for Android binary data.
```

## Issue

A native library from the application or one of its dependencies uses the
reserved archive name `libbinary_blobs.so`. CoreCLR and NativeAOT use this name
for SDK-generated binary data. Allowing another library to use the same path
could replace that data or silently discard the application's library.

## Solution

Rename the conflicting library or change its `ArchiveFileName` metadata so it
does not use `libbinary_blobs.so`. If the library comes from a dependency, update
or correct that dependency's native library packaging.
