# .NET for Android error XA4330

## Example message

```
error XA4330: Native library 'Libraries/arm64-v8a/libcustom.so' uses the reserved name 'libbinary_blobs.so' (archive path 'lib/arm64-v8a/libcustom.so' or ELF SONAME). This name is reserved for .NET for Android binary data.
```

## Issue

A native library from the application or one of its dependencies uses the
reserved archive filename or ELF SONAME `libbinary_blobs.so`. CoreCLR and
NativeAOT use this name for SDK-generated binary data. Android's dynamic linker
can resolve a loaded library by its SONAME even when its packaged filename is
different, so allowing either collision could hide or replace the SDK data.

## Solution

Rename the conflicting library, change its ELF SONAME, or change its
`ArchiveFileName` metadata so neither the SONAME nor archive filename is
`libbinary_blobs.so`. The same reservation applies to native libraries included
inside Java archives. If the library comes from a dependency, update or correct
that dependency's native library packaging.
