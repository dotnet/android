# .NET for Android warning XA4330

## Example message

```
warning XA4330: The R8 JNI remapping data is incomplete. The entry for 'com/example/Peer.run' was not emitted: its signature 'run( ):void' could not be converted to a JNI descriptor.
```

## Issue

The R8 JNI remapping generator skipped an entry because its signature could
not be converted to a JNI descriptor, or because an earlier remapping input
already claims the same source member with a different target. Calls to the
omitted member may fail at runtime if R8 renamed it.

## Solution

Fix the reported signature or change the existing remapping input so that its
source member and target agree with the R8 mapping. Rebuild and confirm that
the warning is gone before relying on the remapped member.
