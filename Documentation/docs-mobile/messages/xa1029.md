# .NET for Android warning XA1029

## Example messages

```
warning XA1029: The 'AotAssemblies' MSBuild property is deprecated. Remove it. For supported .NET 10-and-earlier projects that use Mono, use the 'RunAOTCompilation' MSBuild property instead. CoreCLR and NativeAOT do not use this property.
```

## Issue

This warning is emitted whenever `$(AotAssemblies)` is specified,
including when it is set to `false`.

## Solution

For supported .NET 10-and-earlier projects that use Mono, instead of using:

```xml
<PropertyGroup Condition=" '$(Configuration)' == 'Release' ">
  <AotAssemblies>true</AotAssemblies>
</PropertyGroup>
```

Use instead:

```xml
<PropertyGroup Condition=" '$(Configuration)' == 'Release' ">
  <RunAOTCompilation>true</RunAOTCompilation>
</PropertyGroup>
```

For CoreCLR or NativeAOT projects, remove `$(AotAssemblies)` without
adding `$(RunAOTCompilation)`. Those runtimes do not use the Mono AOT
pipeline. If `$(AotAssemblies)` is `true` while
`$(RunAOTCompilation)` is unset or `true`, the forwarding produces the
build-stopping [XA1044](xa1044.md) error.
