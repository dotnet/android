# .NET for Android informational message XA1040

## Example messages

```
The NativeAOT runtime on Android is a preview feature and not yet suitable for production use. File issues at: https://github.com/dotnet/android/issues
```

## Issue

NativeAOT is a preview runtime option for .NET for Android. When you
enable NativeAOT via `$(PublishAot)=true` for a supported publish or optimized
build, this informational message is emitted to indicate that NativeAOT is not
yet suitable for production use. It is logged at normal importance, not as a
warning, and is not affected by treating warnings as errors.
It is emitted for NativeAOT applications regardless of the value of
`$(EnablePreviewFeatures)`.

The supported runtimes are:

* CoreCLR (the default for Android applications in .NET 11 and later)
* MonoVM, the default for .NET 10 and earlier and available through
  `$(UseMonoRuntime)=true` only on supported targets
* NativeAOT, selected by `$(PublishAot)=true` for supported publish or
  optimized builds

In .NET 11 and later, `$(UseMonoRuntime)=true` is rejected with
[NETSDK1242](https://learn.microsoft.com/dotnet/core/tools/sdk-errors/netsdk1242);
it is not an escape hatch from CoreCLR.

## Solution

This message is informational and does not require any action. To avoid using
the preview runtime, remove `$(PublishAot)=true` from your project file.
