# .NET for Android error XA4329

## Example message

```
error XA4329: Failed to generate the R8 JNI remapping data. The R8 mapping file 'mapping.txt' was not found.
```

## Issue

The R8 JNI remapping generator could not read its mapping, existing remapping
XML, or linked assemblies,
could not read the NativeAOT object used for retention, or found conflicting
entries that cannot be represented in the runtime lookup tables. The diagnostic
includes the specific input or conflicting entries.

## Solution

Check the named input, resolve any conflicting mappings, and rebuild the
application. For a NativeAOT build, ensure the post-ILC object is available
and `NativeAot=true` is set. If the failing input is generated by .NET for
Android, clean and rebuild the application.
