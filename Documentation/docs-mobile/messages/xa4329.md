# .NET for Android warning XA4329

## Example message

```
warning XA4329: Failed to process bundle config file 'BundleConfig.json', split config files will be ignored at run time.
```

## Issue

.NET for Android could not read or parse the custom bundle configuration file.
The build continues, but the runtime ignores split configuration APK files when
searching for assemblies and native libraries.

## Solution

Ensure the custom bundle configuration file exists, contains valid JSON, and is
readable by the build process.
