# .NET for Android error XA4329

## Example message

```
error XA4329: Type map XML file 'obj/Debug/net11.0/android-arm64/example.typemap.xml' was not found.
```

## Issue

The .NET for Android build could not find a type map XML file produced while
processing a managed assembly.

## Solution

This error is expected only for internal build state inconsistencies. Clean and
rebuild the project. If the error persists, verify the build has permission to
write to the intermediate output directory.
