# .NET for Android warning XA4326

## Example message

```
warning XA4326: The R8 JNI remapping data is incomplete. The entry for 'example/Peer.run' was not emitted.
```

## Issue

The build omitted an R8 JNI remapping entry because another remapping input
already owns the same lookup key, or because a Java member signature could
not be converted to a JNI descriptor. The runtime remapping data can
therefore be incomplete for the affected type or member.

## Solution

Review the reported remapping inputs and Java signature. Remove conflicting
custom remapping entries, correct malformed signatures, or add R8 keep rules
for the affected Java type or member.
