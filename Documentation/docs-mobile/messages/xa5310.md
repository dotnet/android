# .NET for Android error XA5310

## Issue

`InstallAndroidDependencies` does not support installing the Android SDK or Java SDK on the current operating system and processor architecture.

## Solution

Install the Android SDK and Java SDK manually by following <https://aka.ms/dotnet-android-install-sdk>, then set `$(AndroidSdkDirectory)` and `$(JavaSdkDirectory)`.
