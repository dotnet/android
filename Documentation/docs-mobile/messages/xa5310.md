# .NET for Android error XA5310

## Example messages

```text
error XA5310: The Android CLI catalog contains no stable platform-tools package with version {version} or later in the supported {major}.x major version. A different major version will not be installed automatically.
```

## Issue

`InstallAndroidDependencies` installs the newest stable `platform-tools`
package in the Android CLI catalog that is at least the requested version and
has the same major version. The catalog contained no such package. Preview
releases, older versions, and packages from a different major version cannot
satisfy this requirement.

## Solution

Check access to Google's Android SDK repository and try again. If Google has
removed the supported major version, use a .NET for Android SDK that supports
the new major version. The installer will not cross major versions automatically
because newer platform-tools can introduce incompatible changes.
