# .NET for Android error XA5310

## Example messages

```text
error XA5310: The Android CLI catalog contains no stable platform-tools package in the supported {major}.x major version. A different major version will not be installed automatically.
```

## Issue

`InstallAndroidDependencies` found no stable `platform-tools` package in its
supported major band. Preview releases and packages from a different major
version cannot satisfy this requirement.

## Solution

Check access to Google's Android SDK repository and try again. If Google has
removed the supported major version, use a .NET for Android SDK that supports
the new major version. The installer will not cross major versions automatically
because newer platform-tools can introduce incompatible changes.
