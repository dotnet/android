# .NET for Android error XA4265

## Example messages

```text
error XA4265: Assembly 'MyBinding.dll' uses a Java peer callback format that requires AndroidTypeMapImplementation=trimmable.
```

## Issue

The referenced binding assembly uses native callbacks that are registered
directly by the trimmable type map. Legacy connector-based type maps cannot
consume this callback format and are no longer supported.

## Solution

Remove the `AndroidTypeMapImplementation` property to use the default
`trimmable` type map, or set it to `trimmable` explicitly. The legacy
`llvm-ir` value is unsupported ([XA4267](xa4267.md)).
