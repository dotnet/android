# .NET for Android error XA4265

## Example messages

```text
error XA4265: Assembly 'MyBinding.dll' uses an unsupported Java peer callback format.
```

## Issue

The referenced binding assembly declares a Java peer callback format that is
not supported by this version of .NET for Android.

## Solution

Reference a version of the binding that uses a supported callback format, or
update .NET for Android to a version that supports the binding's callback format.
