# .NET for Android error XA4265

## Example messages

```text
error XA4265: Assembly 'MyBinding.dll' uses a Java peer callback format that requires AndroidTypeMapImplementation=trimmable.
```

## Issue

The referenced binding assembly uses native callbacks that are registered directly by the trimmable type map. Other type map implementations require legacy connector methods that this binding does not contain.

## Solution

Build the application with `AndroidTypeMapImplementation=trimmable`, or reference a version of the binding that uses legacy connector callbacks.
