# .NET for Android warning XA4324

## Example messages

```
warning XA4324: [arm64-v8a] Unable to delete source file 'obj/Release/net11.0-android/android/assets/Foo.dll'
```

## Issue

While rewriting assemblies for marshal methods support, a temporary source file
could not be deleted. This most commonly happens on Windows when another
process, such as an anti-virus scanner or an editor, holds a lock on the file.

The build continues, but the leftover file remains on disk.

## Solution

Close any process that may be holding the file open, and consider excluding your
build output directories (`bin/` and `obj/`) from anti-virus scanning. Deleting
the `bin/` and `obj/` directories and rebuilding also removes the leftover file.
