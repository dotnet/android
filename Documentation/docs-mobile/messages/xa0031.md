# .NET for Android error XA0031

## Issue

The installed Java SDK is older than the minimum supported by the .NET for Android
SDK. The requirement comes from the SDK's `MinimumSupportedJavaVersion` property,
not from a mapping of `TargetFrameworkVersion` or Android API levels.

## Solution

Install a compatible JDK version, such as the
[Microsoft Build of OpenJDK](/java/openjdk/download).

The current SDK requires JDK 21 or later. Older .NET for Android SDKs can have
different requirements. The JDK must also be within the SDK's
`LatestSupportedJavaVersion` limit; newer, unsupported versions produce
[XA0030](xa0030.md).

If you explicitly set `JavaSdkDirectory`, ensure that it points to a supported JDK.
An explicitly selected older JDK is rejected rather than replaced with another
installed JDK.

## Example messages

```
error XA0031: Java SDK 21.0 or above is required when using .NET 6 or higher. Download the latest JDK at: https://aka.ms/msopenjdk
```
