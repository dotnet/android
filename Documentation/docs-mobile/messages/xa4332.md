# .NET for Android error XA4332

## Example message

```
error XA4332: The library 'MyLibrary.aar' contains the entry '..\..\outside.jar', which cannot be extracted safely because its path is invalid or is nested too deeply.
```

## Issue

An Android library (`.aar`) or library project archive contains an invalid
entry path, or a path more than eight components deep. Paths containing `..`
segments or rooted paths are not allowed.

## Solution

Rebuild the library with relative entry paths without `..` segments and with no
more than eight components. Contact the library author if you do not control
the library.
