# .NET for Android error XA4332

## Example message

```
error XA4332: The library 'MyLibrary.aar' contains the entry '..\..\evil.jar', which cannot be extracted safely because it would be written outside of its extraction directory or is nested too deeply.
```

## Issue

An Android library (`.aar`) or library project archive contains an entry whose
name uses `\` as a directory separator. On macOS and Linux, .NET for Android
converts these separators to `/` after extraction. The converted path would
either be written outside of the directory the library is extracted into, or it
is nested deeper than .NET for Android supports.

## Solution

Rebuild the library so that its archive entries use `/` as the directory
separator and do not contain `..` path segments. Contact the library author if
you do not control the library.
