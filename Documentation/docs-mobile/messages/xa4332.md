# .NET for Android error XA4332

## Example message

```
error XA4332: The .aar archive path 'assets/../../escape.txt' for 'Assets/foo.txt' resolves outside of the archive.
```

## Issue

When building an Android library project, each `@(AndroidAsset)`,
`@(AndroidResource)`, `@(AndroidEnvironment)`, and `@(AndroidNativeLibrary)`
item is placed in the `.aar` at a path computed from its `Link`,
`LogicalName`, or `Abi` metadata. The computed path contains `..` segments
that would place the file outside of the `.aar` archive.

## Solution

Update the item's `Link` (or related) metadata so that it does not contain
`..` segments that escape the archive root.
