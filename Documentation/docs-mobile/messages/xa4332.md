# .NET for Android warning XA4332

## Example message

```
warning XA4332: Failed to read 'obj/Release/net11.0-android/android-arm64/linked/MyLibrary.dll' with debugging symbols for target architecture 'Arm64'. Retrying to load it without debugging symbols. Error details are logged below.
```

## Issue

.NET for Android could not read an assembly together with its debugging
symbols (`.pdb` file). The build loads the assembly again without debugging
symbols and continues. The next warning contains the error details.

## Solution

Make sure that the `.pdb` file matches the assembly and is not damaged. Do a
clean build to remove stale `.pdb` files. If the warning continues, file an
issue at <https://github.com/dotnet/android/issues> and include the error
details.
