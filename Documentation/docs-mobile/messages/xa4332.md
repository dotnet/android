# .NET for Android error XA4332

## Example message

```
error XA4332: The library 'MyLibrary.aar' contains the entry '..\..\outside.jar', which cannot be extracted safely because it would be written outside of its extraction directory, is nested too deeply, or names the same file as another entry that uses '\' as a directory separator.
```

## Issue

An Android library (`.aar`) or library project archive contains an entry whose
name uses `\` as a directory separator. On macOS and Linux, .NET for Android
converts these separators to `/` after extraction. The converted path would
be written outside of the directory the library is extracted into, is nested
deeper than .NET for Android supports, or is the same as the converted path of
another such entry in the same archive. .NET for Android cannot determine which
of those entries should be used.

If an entry that uses `\` names the same file as an entry that uses `/`, the
entry that uses `/` is used and no error is reported.

## Solution

Rebuild the library so that its archive entries use `/` as the directory
separator, do not contain `.` or `..` path segments, and have unique names. Contact the library author if
you do not control the library.
