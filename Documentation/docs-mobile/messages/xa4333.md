# .NET for Android error XA4333

## Example message

```
error XA4333: The .aar library contains input or destination paths that differ only by case. Use distinct names for these paths before packaging the library.
```

## Issue

Two library inputs map to archive destination paths that differ only by case,
such as `assets/Foo.txt` and `assets/foo.txt`. On case-insensitive filesystems,
staging these inputs would overwrite one of the files and produce an incomplete
`.aar`. Packaging rejects these collisions on all hosts for consistent behavior.
Case-only differences in asset source paths or `Link` metadata are also
rejected because MSBuild metadata batching compares these paths without
regard to case. This check is conservative: such inputs are rejected even
when prefix removal would produce identically cased archive paths.
Identical paths with identical casing still use the last input.

## Solution

Rename the conflicting sources or destinations using the inputs' `Link`,
`LogicalName`, or file names so that the paths differ by more than case.
