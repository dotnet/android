# .NET for Android error XA4333

## Example message

```
error XA4333: The extraction output path 'obj/Debug/net11.0-android/lp/library_project_jars' is a symbolic link or junction. Delete it and rebuild the project.
```

## Issue

.NET for Android extracts the contents of Android libraries (`.aar`) into the
intermediate output directory. One of the extraction output directories, or a
file or directory inside it, is a symbolic link or junction. .NET for Android
does not write through links, because doing so could modify files outside of
the intermediate output directory.

## Solution

Delete the reported path (or the whole intermediate output directory, such as
`obj/`) and rebuild the project.
