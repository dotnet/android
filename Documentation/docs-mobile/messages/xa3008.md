# .NET for Android error XA3008

## Issue

This error is emitted when the NativeAOT build fails to extract debug symbols,
strip the linked library, or add its debug-file link using the Android NDK's
`llvm-objcopy`. Incomplete library and debug-symbol outputs are removed so the
next build retries these operations.

## Solution

Check that the official NDK's `llvm-objcopy` tool is installed and functioning
correctly, and that the intermediate output directory is writable. The error
includes the failed command's output.

## Example messages

```
error XA3008: Failed to extract debug info from 'libmonodroid.so'
llvm-objcopy: error: ...
```
