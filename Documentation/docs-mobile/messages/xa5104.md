# .NET for Android error XA5104

## Issue

The build could not locate an installed Android NDK. In .NET 11 and later,
NativeAOT and builds with `AndroidStripNativeLibraries=true` require the NDK.
Ordinary CoreCLR builds do not acquire this requirement.

## Solution

Install the Android NDK or set `AndroidNdkDirectory` to a complete custom
installation containing `source.properties` and the host's LLVM toolchain.
`GetAndroidDependencies` and `InstallAndroidDependencies` include the NDK when
the effective runtime is NativeAOT or native library stripping is enabled.
