# .NET for Android error XA5104

## Issue

The build requires the Android NDK, but a valid NDK installation could not be
located. In .NET 11 and later, this applies to NativeAOT builds
(`$(PublishAot)=true`) and opt-in native library stripping
(`$(AndroidStripNativeLibraries)=true`). Ordinary CoreCLR builds do not require
the NDK.

## Solution

Install the official Android NDK through the Android SDK Manager. If it is
installed in a custom location, set `$(AndroidNdkDirectory)` to the directory
containing the NDK's `source.properties` file:

```dotnetcli
dotnet build -p:AndroidNdkDirectory=/path/to/android-ndk
```

If native library stripping is not needed, remove
`$(AndroidStripNativeLibraries)` or set it to `false`.
