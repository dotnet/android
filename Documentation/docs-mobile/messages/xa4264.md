# .NET for Android error XA4264

This diagnostic is no longer emitted by current .NET for Android SDKs. The
following information is retained for older builds.

## Example message

```text
error XA4264: Java callable wrapper XML file 'obj/Debug/net11.0-android/android-arm64/java-wrappers.xml' was not found.
```

## Issue

The build could not find an intermediate XML file needed to generate Java callable wrappers.

## Solution

Clean and rebuild the project. If the error continues, report the issue at
[dotnet/android](https://github.com/dotnet/android/issues).
