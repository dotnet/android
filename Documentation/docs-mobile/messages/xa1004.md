# .NET for Android error XA1004

## Example messages

```
There was an error opening {filename}. The file is probably corrupt.
Try deleting it and building again.
```

## Issue

This usually happens if a referenced assembly contains a corrupt embedded
*.zip* file in the legacy Xamarin.Android format, for example because
the download of a NuGet package was incomplete. A corrupt *.aar* file is
reported by the `Unzip` MSBuild task instead.

## Solution

The best thing to do is to try to delete the file and do a clean build.

If the problem persists, raise an [issue](https://github.com/dotnet/android/issues/new).
