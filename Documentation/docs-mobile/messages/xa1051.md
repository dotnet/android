# .NET for Android error XA1051

## Example messages

```dotnetcli
error XA1051: The AndroidStaticJniInitFunction MSBuild item is not supported with NativeAOT. Remove it from the project or use a NativeAOT-compatible version of the library that adds it.
```

## Issue

The NativeAOT build no longer generates a native table for
`@(AndroidStaticJniInitFunction)` entries. The built-in cryptography JNI
initializer is called directly during `JNI_OnLoad`; custom initializers
are not invoked.

## Solution

Remove `@(AndroidStaticJniInitFunction)` items from the project. If a library
adds one and requires that initializer, use a NativeAOT-compatible version of
the library or build with a different Android runtime.
