# .NET for Android error XA4266

## Example messages

```text
error XA4266: Assembly 'MyBinding' has different Java peer callback metadata in runtime-specific implementations 'runtimes/android-arm64/lib/net11.0-android/MyBinding.dll' and 'runtimes/android-x64/lib/net11.0-android/MyBinding.dll'. All RuntimeIdentifiers must provide equivalent callback metadata when AndroidTypeMapImplementation=trimmable.
```

## Issue

The application targets multiple runtime identifiers, but a referenced binding package provides different Java callback metadata for the same managed assembly on different Android architectures. The trimmable type map is shared by all packaged architectures and cannot safely reference callbacks that are not present in every implementation.

## Solution

Update the binding package so each runtime-specific managed implementation has equivalent Java callback metadata, or build the application for a single `RuntimeIdentifier`.
