# .NET for Android error XA4232

## Example messages

```
error XA4232: The Android code generation target 'JavaInterop1' is no longer supported. The 'AndroidCodegenTarget' property only supports 'XAJavaInterop1'.
```

## Issue

The `AndroidCodegenTarget` MSBuild property is set to `XamarinAndroid` or
`JavaInterop1`. These code generation targets are no longer supported.

## Solution

Remove the `AndroidCodegenTarget` property to use the default, or set it to
`XAJavaInterop1` in the _.csproj_ file:

```xml
<PropertyGroup>
  <AndroidCodegenTarget>XAJavaInterop1</AndroidCodegenTarget>
</PropertyGroup>
```
