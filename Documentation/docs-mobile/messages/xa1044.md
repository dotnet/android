# .NET for Android error XA1044

## Example messages

```
error XA1044: The MSBuild property 'RunAOTCompilation' is not compatible with the CoreCLR runtime. The build cannot continue while this property is enabled. Remove the property.
```

```
error XA1044: The MSBuild property 'RunAOTCompilation' is not compatible with the CoreCLR runtime. The build cannot continue while this property is set to 'false'. Remove the property. Starting with .NET 11, set 'PublishReadyToRun' to 'false' to disable ReadyToRun (R2R) AOT compilation.
```

## Issue

This error indicates that a Mono-specific MSBuild property is set in
the project file, but the project is configured to use a non-Mono
runtime, such as CoreCLR or NativeAOT. When the property is `true`, the
build resets it to `false` so it is not passed to non-Mono build steps,
then stops with XA1044. This is not a warning or a silent no-op.

For CoreCLR applications, setting `RunAOTCompilation` to `false` also
produces this error. It does not disable ReadyToRun compilation.

Properties that trigger this error include:
- `RunAOTCompilation` — Enables Mono AOT compilation.
- `EnableLLVM` — Enables LLVM for the Mono AOT compiler.

## Solution

Remove the Mono-specific property from your project file or
`Directory.Build.props`. Retain it only in project files or conditions
that apply exclusively to supported .NET 10-and-earlier Mono targets.

ReadyToRun and NativeAOT are separate compilation models. They are not
one-to-one replacements for Mono AOT settings.

Starting with .NET 11, to disable ReadyToRun (R2R) AOT compilation for
CoreCLR applications, remove `RunAOTCompilation` and set
[`PublishReadyToRun`](../building-apps/build-properties.md#publishreadytorun)
to `false` instead:

```xml
<PropertyGroup>
  <PublishReadyToRun>false</PublishReadyToRun>
</PropertyGroup>
```
