# .NET for Android error XA1044

## Example messages

```
error XA1044: The MSBuild property 'RunAOTCompilation' is not compatible with the CoreCLR runtime. The build cannot continue while this property is enabled. Either remove the property or guard it with a condition: Condition="'$(UseMonoRuntime)' == 'true'"
```

## Issue

This error indicates that a Mono-specific MSBuild property is set in
the project file, but the project is configured to use a non-Mono
runtime, such as CoreCLR or NativeAOT. The build resets the property to
`false` so it is not passed to non-Mono build steps, then stops with
XA1044. This is not a warning or a silent no-op.

Properties that trigger this error include:
- `RunAOTCompilation` — Enables Mono AOT compilation.
- `EnableLLVM` — Enables LLVM for the Mono AOT compiler.

The `UseMonoRuntime` condition below is valid only for supported .NET
10-and-earlier Mono targets. In .NET 11 and later, setting
`UseMonoRuntime=true` is rejected with
[NETSDK1242](https://learn.microsoft.com/dotnet/core/tools/sdk-errors/netsdk1242).

## Solution

Remove the Mono-specific property from your project file or
`Directory.Build.props`, or guard it with a runtime condition:

```xml
<PropertyGroup Condition=" '$(UseMonoRuntime)' == 'true' ">
  <RunAOTCompilation>true</RunAOTCompilation>
</PropertyGroup>
```

ReadyToRun and NativeAOT are separate compilation models. They are not
one-to-one replacements for Mono AOT settings.
