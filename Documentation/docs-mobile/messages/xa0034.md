# .NET for Android warning XA0034

Starting with .NET 12, this diagnostic is no longer emitted by .NET for Android.
The following information is retained for earlier releases. For unrecognized
Java version output, see [XA0033](xa0033.md).

## Issue

An exception was raised when .NET for Android tried to get the Java SDK version.

## Solution

Make sure you have a valid Java installation installed.
