# .NET for Android error XA4256

## Example message

```
error XA4256: Only one 'JavaArtifact' is allowed for 'AndroidMavenLibrary' item 'example-library'.
```

## Issue

An item that accepts one Maven artifact specifies multiple artifacts in its
`JavaArtifact` metadata.

## Solution

Update the item so its `JavaArtifact` metadata contains exactly one Maven
artifact in `group-id:artifact-id:version` format. Use separate items when
you need to reference multiple artifacts.
